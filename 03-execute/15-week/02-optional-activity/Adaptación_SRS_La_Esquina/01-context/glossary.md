# Glosario

**Estado:** 🟢 Estable  
**Última actualización:** 2025-06  
**Autor:** Equipo La Esquina

---

| Término | Definición |
|---------|-----------|
| **Administrador** | Usuario del sistema con permisos completos: gestión de productos, inventario, reportes y usuarios |
| **Cajero** | Usuario del sistema con permisos operativos: registro de ventas y generación de facturas |
| **Cliente** | Persona que compra en el supermercado; actor indirecto que no interactúa directamente con el sistema |
| **Producto** | Artículo registrado en el sistema con nombre, precio, categoría y stock disponible |
| **Inventario** | Registro centralizado y actualizado en tiempo real de la cantidad disponible de cada producto |
| **Venta** | Transacción registrada en el sistema que refleja la compra de uno o más productos por un cliente |
| **Factura** | Documento generado automáticamente al registrar una venta, con el detalle de productos y el total a pagar |
| **Stock** | Cantidad de unidades disponibles de un producto en el inventario |
| **Alerta de stock bajo** | Notificación automática del sistema cuando el stock de un producto cae por debajo del umbral mínimo definido |
| **Reporte** | Resumen generado por el sistema sobre ventas o inventario en un rango de fechas determinado (diario, semanal, mensual) |
| **RF** | Requerimiento Funcional — define qué debe hacer el sistema |
| **RNF** | Requerimiento No Funcional — define cómo debe comportarse el sistema (rendimiento, seguridad, usabilidad) |
| **RN** | Requerimiento de Negocio — define objetivos estratégicos del supermercado que el sistema debe apoyar |
| **CU** | Caso de Uso — describe la interacción entre un actor y el sistema para lograr un objetivo concreto |
| **SRS** | Software Requirements Specification — documento formal que recoge todos los requerimientos del sistema |
