## Catálogo de Requerimientos Funcionales

| ID | Nombre | Descripción | Fuente | Prioridad |
|----|--------|-------------|--------|-----------|
| RF01 | Registro de productos | El sistema debe permitir registrar productos con nombre, precio, categoría y stock | Entrevista | **Alta** |
| RF02 | Actualización de productos | El sistema debe permitir editar la información de productos existentes | Observación | **Alta** |
| RF03 | Eliminación de productos | El sistema debe permitir eliminar productos del inventario | Administrador | **Media** |
| RF04 | Consulta de productos | El sistema debe permitir buscar productos por nombre o categoría | Encuesta | **Alta** |
| RF05 | Gestión de inventario | El sistema debe controlar entradas y salidas de inventario automáticamente | Observación | **Alta** |
| RF06 | Registro de ventas | El sistema debe registrar cada venta realizada con sus productos, cantidades y totales | Cajero | **Alta** |
| RF07 | Generación de factura | El sistema debe generar automáticamente una factura con el detalle de productos al confirmar una venta | Encuesta | **Alta** |
| RF08 | Control de usuarios | El sistema debe permitir crear y gestionar usuarios con roles Administrador y Cajero | Administrador | **Media** |
| RF09 | Reportes de ventas | El sistema debe generar reportes de ventas diarios, semanales y mensuales | Administrador | **Alta** |
| RF10 | Alertas de stock bajo | El sistema debe notificar cuando un producto tenga stock por debajo del umbral mínimo | Observación | **Alta** |
