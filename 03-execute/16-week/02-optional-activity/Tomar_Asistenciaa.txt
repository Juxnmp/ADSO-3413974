#Requerimientos Funcionales 

**RF-01. 
El sistema deberá generar un código QR para cada sesión de asistencia.

**RF-02. 
El sistema deberá actualizar automáticamente el código QR en intervalos de tiempo definidos para evitar su reutilización.

**RF-03. 
El sistema deberá verificar que el código QR escaneado se encuentre vigente antes de registrar la asistencia.

**RF-04. 
El sistema deberá verificar que el dispositivo desde el cual se registra la asistencia se encuentre dentro del área autorizada para permitir el registro.

**RF-05. 
El sistema deberá permitir un único registro de asistencia por participante en cada sesión.

**RF-06. 
El sistema deberá almacenar la fecha y la hora exacta en que se realizó el registro de asistencia.

**RF-07. 
El sistema deberá permitir consultar los registros de asistencia por participante, fecha o sesión.

**RF-08. 
El sistema deberá generar reportes de asistencia por sesión o por rango de fechas.

**RF-09. 
El sistema deberá mostrar el total de asistentes y de inasistencias por sesión.

**RF-10. 
El sistema deberá informar al usuario si el registro de asistencia fue exitoso o si fue rechazado por un código inválido, vencido o por no cumplir con la validación de ubicación.
